# Retired Qt Widgets interface (2026-10-27)

The first control center was built from Qt Widgets (`live.py`, `skills.py`, `project.py`,
`assistant.py`, `plot.py`). It was replaced by the Astra redesign (`scripts/studio_app/web/`,
hosted in Qt WebEngine and wired to the same back end through `scripts/studio_app/bridge.py`).
These files are kept for reference only; they are not imported by the application.
